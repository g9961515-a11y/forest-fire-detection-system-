# 🌲 Forest Fire Detection System Using NodeMCU ESP8266 and KiwisIoT

## 📌 Project Description

The Forest Fire Detection System is an IoT-based project designed to detect early signs of forest fires by continuously monitoring environmental conditions.

This system uses a NodeMCU ESP8266 microcontroller, an MQ-2 smoke sensor, and a DHT11 temperature and humidity sensor to monitor smoke levels, temperature, and humidity in the surrounding environment.

The collected sensor data is transmitted through Wi-Fi to the KiwisIoT cloud platform, allowing users to monitor environmental conditions remotely in real time.

When smoke levels or temperature exceed predefined threshold values, the system can trigger an alert to warn users about potential fire risks. This helps support early detection and faster emergency response.

## ⚙️ Working Principle

1. The MQ-2 sensor detects smoke in the surrounding environment.
2. The DHT11 sensor measures temperature and humidity.
3. NodeMCU ESP8266 collects the sensor readings.
4. The collected data is transmitted to the KiwisIoT platform using Wi-Fi.
5. Users monitor live sensor values through the cloud dashboard.
6. When predefined threshold conditions are reached, the system generates a warning.
